## 处理流程

1. 读取第一个工作表，首行为表头。
2. **`src/jd.py` 不读取本规则文件**，直接把 `费用项` 作为 `分类`；缺少该列时跳过该文件。
3. `金额` 转为数值；`收支方向` 含 `支出` 且金额为正时按负数统计。
4. 生成透视表：按分类汇总 `金额` 与 `行数`，并追加 `总和` 行（不计算净值和税率）。

## 分类规则

- 规则按序号从小到大匹配，**第一条命中的规则决定分类**，序号越小优先级越高。
- 同一分类下有多行条件时，任意一行命中即可；一行内用“且”连接的条件需同时满足。
- “包含”为子串匹配，“等于”会先去掉首尾空格再比较。
