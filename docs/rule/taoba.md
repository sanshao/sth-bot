# 淘宝账单分类规则

本文档根据 `src/taobao.py` 中现有规则整理，描述淘宝账单导入后的分类逻辑。

## 基础处理规则

- 读取 Excel 文件的第一个工作表。
- 从第 5 行作为表头读取数据，并跳过文件末尾 4 行。
- 清理所有列名两侧的空格。
- 新增“净值”列，计算方式为：`收入金额（+元） + 支出金额（-元）`。
- 新增“分类”列，按下方规则从上到下依次匹配。
- 如果一条流水命中多条规则，以最先匹配到的规则为准。
- 如果没有命中任何规则，分类为“其它-未分类”。
