# 天猫账单分类规则

本文档根据 `src/tmall.py` 中现有规则整理，描述天猫账单导入后的分类逻辑。

## 基础处理规则

- 读取 Excel 文件的第一个工作表。
- 从第 5 行作为表头读取数据，并跳过文件末尾 4 行。
- 清理所有列名两侧的空格。
- 新增“净值”列，计算方式为：`收入金额（+元） + 支出金额（-元）`。
- 新增“分类”列，按下方规则从上到下依次匹配。
- 如果一条流水命中多条规则，以最先匹配到的规则为准。
- 如果没有命中任何规则，分类为“其它-未分类”。

## 税率规则

对于分类中包含“交易收款”、“限时红包”或“多买多省”的流水，系统会根据“商品名称”自动判定税率：

- **9%**：商品名称包含“鲜奶”、“鲜牛乳”、“鲜牛奶”或“乳糖牛奶”。
- **13%**：商品名称包含“酸奶”、“发酵乳”、“发酵奶”、“巧克力奶”、“藜麦牛奶燕麦”、“试乳牛乳饮品”、“牛乳饮品”、“牛乳茶乳饮料”或“原味蜂蜜0蔗糖”。
- **其它情况**：不设置税率。

该税率目前仅用于在“透视”工作表中对特定分类进行细分显示（如“天猫-交易收款9%”）。

- 生成新的整理文件，文件名为原始文件名加 `_整理.xlsx`。
- 输出文件包含两个工作表：

  - “透视”：按“分类”汇总“净值”，并追加“总和”行。
