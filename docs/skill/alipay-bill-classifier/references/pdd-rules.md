## 处理流程

1. 自动查找含 `商户订单号` 的行作为表头（找不到时默认第 5 行）。
2. 金额列转为数值，新增 `净值 = 收入金额（+元） + 支出金额（-元）`。
3. **`run.py` 当前调用的 `src/pdd.py` 不读取本规则文件**，直接把 `业务描述` 作为 `分类`。
4. `src/pdd1.py` 才会使用本规则：按规则表匹配，未命中时以原始 `业务描述` 作为分类，并把 `净值`、`分类`、`税率` 放到 `支出金额（-元）` 之后。
5. 生成透视表：按分类汇总 `净值` 与 `行数`，并追加 `总和` 行。

## 分类规则

- 规则按序号从小到大匹配，**第一条命中的规则决定分类**，序号越小优先级越高。
- 同一分类下有多行条件时，任意一行命中即可；一行内用“且”连接的条件需同时满足。
- “包含”为子串匹配，“等于”会先去掉首尾空格再比较。
