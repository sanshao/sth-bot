## 处理流程

1. 读取第一个工作表，以第 5 行为表头（`header=4`），跳过末尾 4 行汇总。
2. 清理列名两侧空格。
3. `备注` 为空（含空白/制表符）时，用 `商品名称` 填充 `备注`，以便规则匹配。
4. 新增 `净值 = 收入金额（+元） + 支出金额（-元）`（支出在源表中已是负数）。
5. 按本文规则表从上到下匹配，新增 `分类` 列；未命中为 `其它-未分类`。
6. 按商品名称新增 `税率` 列（规则见总览文档的“税率与透视细分”）。
7. 把 `净值` 移到 `支出金额（-元）` 与 `账户余额（元）` 之间。
8. 生成透视表：按分类汇总 `净值` 与 `行数`，并追加 `总和` 行。
